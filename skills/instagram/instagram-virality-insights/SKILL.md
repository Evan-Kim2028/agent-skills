# Instagram Virality & Retention Insight Quality

## Core law: the open cognitive loop

Reels travel when frame 0 opens a question the brain must chase; they stall
when frame 0 is resolved. Confrontation (belief attack) is **one** loop type,
not the only one. A finished chart = no loop = the measured **0.003–0.09
v/f** band (CardLadder/GemRate).

| Loop family | Mechanic |
|---|---|
| Belief attack | "You're wrong about X" |
| Unresolved wager | Outcome revealed at the end |
| Closing window | Urgency / deadline |
| Rank churn | Race, winner hidden |
| Scale violation | True-size "whoa" |
| Crisis / news | "What happens to us now?" |

## Retention mechanics (ranked by evidence strength)

1. **Duration** — 12–25s for data reels; 31s+ = measured losing band. Length never fixes a resolved open.
2. **Familiar-entity-first** — a recognizable card/entity IS a hook before any claim text.
3. **Payoff cadence** — ~3–5s; text cards that ARE the story ≠ dead air. True dead air = logo stings / empty wipes.
4. **Loop seam** — last ~2s should visually rhyme with first ~2s (replays count as watch time).
5. **Data as evidence** inside a story with stakes, never as the subject.

## Share/save psychology

- Sends-per-reach is the top expansion signal (Mosseri-confirmed). This is a caption-layer pattern (Youshaei hook-body-send-ask; Mosseri sends-per-reach), not a VO pattern — the send-ask is mandatory but lives in the caption (and optionally a pinned comment), never spoken or on-screen in the final beat.
- Recipient-named send-asks ("send this to the friend who still…") beat quota asks, and beat polls (polls → comments = weakest lever).
- Saves come from a portable rule or reference numbers held static ~2s.
- Directive framing ("buy this, avoid that", "hold three years") gets reposted; observations don't.
- Identity/debate bait (era vs era, which side are you on) drives tagging.

## Escaping the test pool (small accounts)

- Scoring is per-video, not per-account: the first pool measures skip + sends + completion regardless of follower count.
- Engineer one save reason AND one share reason into every reel.
- Trial Reels need 1,000+ followers — check before recommending.
- Collab leverage: data brands travel by powering a personality's reel (double.holo pattern) — SilphCo-as-source is a valid distribution play.

## Anti-patterns

Resolved frame 0 (calm green stat) · analytics as subject · poll-only CTA ·
>30s data recaps · polish iterations inside a dead template · judging hooks by
wording without checking the muted frame-0 visual.

## Optional appendix: live recon protocol

**OPTIONAL.** Use only when fresh evidence is needed, not routinely — recon
findings decay and one session's sample is directional, not proof.

### Goal

Find organic winner Reels on live Instagram outside the follow graph, vet
whether a view count is real (v/f) or a fluke, and extract the frame-0
mechanic + CTA driving it.

### Protocol

| Step | Action |
|------|--------|
| 1. Keyword search | Open `https://www.instagram.com/explore/search/keyword/?q=<query>` — top results are IG's own ranking for the topic, not the follow graph |
| 2. Open winner reels | Click into top results, note the account |
| 3. Vet the account | Open `/<handle>/reels/`, read "View Count Icon" values vs follower count. Consistent v/f **>1** at small scale beats one outlier |
| 4. Extract frame-0 | Screenshot frame-0 of winners (that IS the muted scroller's view); read caption/comments for CTA + debate patterns |
| 5. Negative controls | Also record stuck accounts (data-without-stakes accounts sitting at 5–200 views) — these disprove "just post data" |

### Practical notes

| Note | Why it matters |
|------|-----------------|
| Web Insights hide skip/watch-time | Only the mobile app exposes those; web/desktop shows views/interactions/shares/saves |
| Grid views are lifetime, not recent | Check post dates before treating a view count as fresh signal |
| Snapshots may need a 3–4s wait | Let the reel render before screenshotting frame-0 |
| Feed (`/reels/`) is mostly general-viral | Search beats feed for niche recon |
| Don't interact | No likes/follows — keep the account's graph clean for repeat recon |
