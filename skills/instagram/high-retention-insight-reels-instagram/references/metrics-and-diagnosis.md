# Reels metrics map + post-publish diagnosis

Canonical copy lives on the **instagram** hub (`skills/instagram/instagram/SKILL.md`).  
This file is a short pointer so storyboard/rank sessions can open a stable path.

## Always

1. **Skip rate** = hook (first ~3s). Healthy ~30–40%; kill ≥50–60%.
2. **Retention curve / avg % watched** = story after the hook — not the same problem as skip.
3. Native reach order: skip → share → like → save → repost → comment.
4. Silph ship order: skip → share/DM → save → watch/replays → likes → repost/comment.
5. Post-publish: **one** primary action from the hub decision tree (`rewrite-hook`, `add-share-trigger`, `add-save-payload`, `cut-mid`, `tighten-or-split`, `kill-template`, `clone-mechanism`).

See hub sections **Native metrics map** and **Post-publish diagnosis playbook**.
