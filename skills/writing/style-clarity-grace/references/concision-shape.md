# Concision and shape

Cut **after** characters, actions, topic, and stress are right. Short
turgid prose is still turgid.

## What to cut (Williams-style categories)

| Kind | Example cut |
|------|-------------|
| Redundant pair | *each and every* → *each* |
| Redundant modifier | *future plans* → *plans*; *true fact* → *fact* |
| Meaningless modifier | *basically, really, definitely, quite, various* |
| Obvious implication | *completely finish* → *finish* |
| Fake hedge | *it seems that it might be possible that` → name the uncertainty once |
| Metadiscourse | *It is worth noting that*, *as mentioned above* |
| *The fact that* | *owing to the fact that* → *because* |
| Negative evasion | *did not succeed* → *failed* (same as Strunk) |

**Preserve:** a hedge that is a real epistemic limit, a number, a name,
a seam, a mixed feeling. Those are not wordiness.

## Long sentences

Length is not the defect. A long sentence is fine when:

- subject and verb arrive early
- the stress is at the end
- modifiers trail, they don’t interrupt

Fix a long sentence by reshaping, not by a 12-word cap:

1. Close the subject–verb gap.
2. Move trailing detail after the verb.
3. Split only when there are two points.

`writing-prose` still wants uneven rhythm. Do not turn every page into
the same 18-word sentence after a Williams pass.

## Elegance (last, optional)

Balance and parallelism help *after* clarity:

- Match form to matched content (same as Strunk rule 15).
- Climactic order: weaker / shorter before stronger / longer.
- Don’t add a second clause just to sound oratorical.

If elegance and clarity fight, keep clarity.
