# Usage — real rules vs folklore

Williams sorts “rules” so you stop enforcing English-teacher folklore
on already-clear prose.

## Real rules

Violations mark the writer as not knowing the language, or they change
meaning. Fix these:

- Subject–verb agreement
- Wrong pronoun case that confuses who did what
- Double negatives that flip the claim
- Modifier attached to the wrong noun (dangler — also Strunk 7)

## Folklore (do not enforce)

Invented or overstated school rules. Native and professional writers
break them constantly. Do not “correct” these as hard fails:

- Never split an infinitive
- Never end a sentence with a preposition
- Never start a sentence with *and* / *but* / *because*
- Never use the passive
- Never use *which* for restrictive clauses (house style may still pick
  *that*; it’s optional, not moral)
- Never use *they* as a singular (follow the project’s house style)

## Optional / house

Series comma, *data* as singular, contractions, *can* vs *may* — pick
the house rule and be consistent. `elements-of-style` defaults to the
1920 series comma. Don’t fight it unless the user says otherwise.

## Agent failure mode

LLMs love folklore. A Williams pass that “fixes” a split infinitive
and converts a good passive is a failed pass. If the character is in
the subject and the stress is at the end, stop.
