# Padding and misuse (Strunk 1920, ch. V — still useful)

Skip dated entries (*shall/will*, *folk*, *student body*, *thanking you in
advance*, split-infinitive ban). Recast the sentence; don’t synonym-swap.

| Watch | Do |
|-------|----|
| *as to whether* | *whether* |
| *but* after *doubt* / *help* | *no doubt that* / *could not help seeing* |
| *case* | name the thing; *in many cases* → *often* |
| *character* / *nature* | usually delete (*acts of a hostile character* → *hostile acts*) |
| *claim* (verb) | *lay claim to*; don’t use for *assert* unless that’s meant |
| *compare to* vs *compare with* | *to* = likeness; *with* = relative merits |
| *consider as* | *consider* + complement (*I consider him intelligent*) |
| *different than* | *different from* |
| *due to* as a sentence adverb | *because of* / *owing to* |
| *etc.* | don’t tack onto a list already introduced by *such as* |
| *the fact that* | see composition rule 13 |
| *factor* / *feature* | delete or name the actual cause / part |
| *however* = nevertheless | usually not first in the clause |
| *interesting* | say why, or cut the throat-clearing opener |
| *kind of* / *sort of* | not a hedge for *rather* |
| *less* vs *fewer* | *fewer* for count nouns (house style may ignore) |
| *like* for *as* | *like* + noun; *as* + clause |
| *along these lines* | name the method |
| *literally* | only if it happened |
| *most* for *almost* | *almost* |
| *one of the most* | don’t open a paragraph with it |
| *phase* | a stage of change, not a synonym for *aspect* |
| *possess* | don’t use as a fancy *have* |
| *respective(ly)* | usually omit |
| *so* as intensifier | cut or pick a real word |
| *state* for *say* | *say* unless it’s a formal statement |
| *system* | often needless |
| *very* | spare; prefer a stronger word |
| *while* for *and* / *but* / *although* | use the word you mean |
| *worth while* | vague approval — specify |
| *as good or better than* | *as good as his, or better* |

`whom`: object in its own clause. Don’t write *whom he said was* — that’s *who*.
